# 🌲 Federated Proactive Forest

Welcome to the documentation for **Federated Proactive Forest**, a research project on horizontal federated learning with advanced tree aggregation strategies.

## Overview

This project implements a hexagonal architecture to explore various aggregation strategies for **Proactive Forest** models in distributed, non-IID environments.

### Key Features

*   **8 Aggregation Strategies**: S1-S7 and the novel Progressive Windows (PW) strategy.
*   **Non-IID Support**: Native support for Dirichlet-based data heterogeneity.
*   **Hexagonal Architecture**: Clear separation between domain logic and infrastructure.
*   **Interactive UI**: Streamlit-based dashboard for experimentation.
