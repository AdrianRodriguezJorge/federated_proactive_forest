# Guide

This guide explains how to use the Federated Proactive Forest project.

## Installation

Please refer to the project's root `README.md` for detailed installation steps.

## Basic Usage

To run a federated learning experiment, you can use the CLI or the Streamlit interface.

### Running with CLI

```bash
python -m src.interfaces.cli.main --config configs/experiments/exp_s1_simple_pool.yaml
```

### Running with Streamlit

```bash
streamlit run src/interfaces/streamlit/app.py
```
